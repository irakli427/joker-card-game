ჯოკერი არის python პროგრამა, რომელიც ოთხ მოთამაშეს აძლევს საშუალება თამაშის საშუალებას. პროექტში გამოყენებულია Deck, Player, 
და Game კლასები. თამაში შედგება 16 დარიგებისგან.

Deck კლასი პასუხისმგებელია დასტის შექმანაზე, ნებისმიერ დარიგებაში პირველ მოთამაშეს აძლევს საშუალებას აირჩიოს კოზირი ან კოზირის
გარეშე ჩაატაროს დარიგება.

Player კლასი ქმნის მოთამაშეებს ანიჭებს შეაბამის ატრიბუტებს. ასევე მოიცავს მეთოდებს: deal_cards და play_card, რომლებიც 
პასუხისმგებლები არიან კარტის დარიგებასა და თამაშის დროს კონკერტული კარტის არჩევაზე.

Game კლასი 'ქმნის' თამაშს, განსაზღვრავს თამაშის წესებს და მოთამაშეების შედეგებს ინახავს. კლასი რამოდენიმე მეთოდს:

get_last_player,get_first_player აგენერირებს პირველ და ბოლო მოთამაშეს.

ask_for_bids აძლევს საშუალებას გამოთქვან ვარაუდი წაღებული კარტების რაოდენობის შესახებ.

gather_card აგროვებს ჩამოსულ კარტებს, determine_winner_card და determine_card_taker კი განსაზღვრავენ გამარჯვებულ კარტს და 
შესაბამისად კარტების "წამღებ" მოთამაშეს.

rotate_list_for_card_chooser მეთოდი უზრუნველყოს თამაშის პერიოდში კარტის ჩამომსვლელ მოთამაშეთა სწორ თანმიმდევრობას.
(წინა წამღებმა უნდა გააკეთოს პირველი სვლა)

calculate_points თვლის მოთამაშეთა ქულებს ყოველი დარიგების შემდეგ.

initial_max_points და new_max_point კი უზრუნველყოფენ ბონუსის დათვლას პრემიაზე გასული მოთამაშეთათვის.

update_score და add_bonus_points კი ინახავენ განაცლებულ ქულებს json ფორმატის ფაილში.

single_deal არის ფუნქცია რომელიც გამოიყენება თითოეული დარიგების გასაშვებლად.

start_game კი თამაშის დასაწყებად.

თამაშის გასაშვებად გამოიყენება Deck მოდული.
